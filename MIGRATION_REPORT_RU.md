# Отчет о миграции NU HPC Wiki

## Что обработано

В архиве находились шесть MHTML-снимков от 4 августа 2026 года: главная страница, Quick Start, Systems, Job Submission, Software и Policies. Текст нормализован в Markdown, вложенные изображения извлечены локально, а исходная редакция сохранена в `docs/old/`.

Новая редакция находится в `docs/new/`. Для каждой статьи создан полный unified diff с цветным просмотром на страницах `docs/compare/`.

## Существенные исправления

- Исправлено переполнение целых чисел в OpenMP-примере; новая программа скомпилирована и проверена.
- Исправлены неработающие директивы LAMMPS без `#SBATCH` и конфликтующее ручное смешивание модулей компилятора/MPI.
- Исправлен синтаксис Conda: `conda activate` и `conda install --name`.
- Убрано утверждение, что ID заданий всегда состоит из четырех или пяти цифр.
- Исправлено описание раннего завершения и достижения wall time.
- Поведение pending-заданий теперь объясняется через Slurm reason codes, без универсального обещания «будет ждать бесконечно».
- Разделены версия CUDA, поддерживаемая драйвером, и реально загруженный toolkit.
- Убрана безусловная рекомендация `-march=native -ffast-math`, способная ухудшить переносимость и воспроизводимость.
- Gaussian использует согласованные CPU/RAM-настройки и по возможности node-local scratch; выбор конкретного idle-узла удален.
- Фраза «четыре QoS» не повторяется, поскольку в источнике перечислено пять.

## Конфликты, которые нельзя достоверно решить только по архиву

- CPU H100-узлов Irgetas: EPYC 9654 в Systems и EPYC 9454 в Policies.
- Скорость/топология хранения: в тексте встречается 1 Mbit/s, а в инвентаризации — 1 Gb/s Ethernet и InfiniBand.
- Применимость BeeGFS-команд к Muon не согласуется с описанием его хранилища.
- В архиве отсутствовали публичные FQDN, VPN/MFA, SSH fingerprints и процедура получения аккаунта.
- Все квоты, QoS, partition limits, module names, backup guarantees и поддержка `srun`/PMIx требуют сверки с живыми системами.

Полный перечень вынесен в `docs/contribute/maintainer-checklist.md`. До его закрытия новую Policies нельзя обозначать как утвержденную эксплуатационную политику.

## Оформление и Git

Использован Material for MkDocs: адаптивная навигация, поиск, светлая/темная темы, копирование кода, admonitions и локальные изображения. Клиентский переключатель открывает Original, Current и Changes для одной статьи.

Добавлены:

- ссылки Edit/View source через `repo_url` и `edit_uri`;
- авторы и даты из Git при `ENABLE_GIT_PLUGINS=true`;
- CODEOWNERS, шаблон pull request и Dependabot;
- строгая GitHub Actions сборка и публикация Pages;
- инструкция по branch/PR review и опциональному versioning через `mike`;
- lock-файл проверенного Python-окружения.

Перед размещением нужно заменить все `CHANGE-ME` в `mkdocs.yml` и `.github/CODEOWNERS`.
